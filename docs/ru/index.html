Двухпанельный файловый менеджер для тех, кто живёт на клавиатуре

Marlia переносит на Mac привычную работу в стиле Total Commander. F5 копирует в соседнюю панель, F6 перемещает, Tab переключает панели. Приложение построено на нативных представлениях AppKit, поэтому не тормозит даже в папках с тысячами файлов.

      Возможности

      Всё, что должен уметь файловый менеджер, не отрывая рук от клавиатуры

      Две панели, вкладки, три вида

      Tab · ⌘1 ⌘2 ⌘3

      Список, значки и колонки в стиле Finder с колонкой предпросмотра. У каждой панели своя история, а каждая папка помнит, как вы её отсортировали.

      Подход Total Commander

      F5 · F6

      Копирование и перемещение в соседнюю панель, выбор набором имени, выделение по маске вроде *.jpg, инверсия выделения.

      Фоновые операции

      ⌘Z · ⇧⌘Z

      Копирование, перемещение, дублирование, удаление в корзину и переименование идут в фоне, их можно приостановить или отменить. Отмена помнит 50 шагов и переживает перезапуск.

      Архивы

      zip · tar.gz/bz2/xz

      Создание, распаковка и просмотр архивов системными утилитами, включая ZIP с паролем. Распаковка защищена от путей zip-slip.

      Рабочие пространства

      symlinks

      Соберите файлы со всего диска в одну папку ссылок. Ничего не копируется и не перемещается, а удаление убирает только ссылку.

      Поиск, фильтр, просмотр

      ⌘F · ⌥⌘F · Space

      Рекурсивный поиск по подстроке или регулярному выражению, мгновенный фильтр, Quick Look по пробелу, окно свойств и живая информационная панель.

      Своя в macOS

      Finder · AirDrop · SMB

      Перетаскивание в Finder и из него, цветные теги, AirDrop, открытие в Терминале, подключение к SMB, извлечение дисков и установка приложений прямо из .dmg. Копии на флешках не обрастают файлами ._.

      Свои сочетания клавиш

      ⌘, · ⌘?

      Любое сочетание меняется в настройках. Избранное 1–9 открывается по ⌥⌘1…⌥⌘9, полный список есть в справке.

      Командная палитра

      ⇧⌘P · ⇧⌘G

      Любая команда меню в паре нажатий: нечёткий поиск находит её по нескольким буквам. «Перейти к папке» принимает путь с дополнением по Tab и помнит недавние папки.

      Сравнение папок

      ⇧F2 · ⌥⌘S

      Одно нажатие выделяет в обеих панелях то, чего нет в соседней или что новее. ⌘← и ⌘→ открывают папку в другой панели, а размер папок можно посчитать и отсортировать по нему.

      Свои команды

      Commands · zsh

      Запускайте свои shell-скрипты для выделенных файлов из меню Commands, палитры или по сочетанию клавиш, с паузой и отменой, как пользовательские команды в Total Commander.

      Переименование по метаданным

      [Date] · [Track]

      Пакетное переименование с предпросмотром всех новых имён: дата и время из EXIF или видео, номер трека, исполнитель и название из тегов, смена регистра.

      Установка

      Запуск за минуту

      1. Скачайте образ.
        Marlia-1.3.dmg или любую версию со страницы Releases.
      2. Перетащите Marlia в «Программы».
        В образе рядом лежат приложение и ярлык папки «Программы».
      3. Первый раз откройте вручную.
        Щёлкните Marlia.app правой кнопкой и выберите «Открыть». В macOS 15 и новее откройте «Системные настройки» → «Конфиденциальность и безопасность» и нажмите «Всё равно открыть».
      4. По желанию: дайте полный доступ к диску.
        Тогда «Рабочий стол», «Документы» и «Загрузки» будут открываться без повторных запросов.

      Почему macOS переспрашивает

      Marlia подписана ad-hoc, без Apple Developer ID, поэтому Gatekeeper останавливает её при первом запуске. Если macOS пишет, что приложение «повреждено и не может быть открыто» (так часто бывает после скачивания в браузере или по AirDrop), снимите атрибут карантина:

      xattr -cr /Applications/Marlia.app

      Хотите собрать сами? Xcode-проекта нет, только один скрипт: ./build.sh --run.

      Конфиденциальность

      • Само приложение Marlia ничего никуда не отправляет: ни аналитики, ни отчётов о сбоях, ни проверки обновлений. В сеть оно выходит, только когда вы сами об этом просите, например при подключении к SMB-серверу.
      • Сайт не использует cookies, аналитику и трекинг. Шрифты и изображения загружаются с самого сайта.
      • Выбранный язык запоминается в вашем браузере (local storage) и никуда не передаётся.
      • Чтобы показать последнюю версию, страница при каждом посещении один раз запрашивает у GitHub API сведения о релизах Marlia. При этом GitHub получает ваш IP-адрес.
      • Сайт размещён на GitHub Pages. Как и любой хостинг, GitHub ведёт журналы запросов, включая IP-адреса. Подробнее в GitHub Privacy Statement.
