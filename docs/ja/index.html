無料・オープンソース · macOS 13.5+ · Apple シリコン

キーボード派のための2ペイン・ファイルマネージャー

Marlia は Total Commander の操作感を Mac に持ち込みます。F5 で反対側のペインへコピー、F6 で移動、Tab でペインを切り替え。ネイティブの AppKit ビューで作られているので、数千ファイルのフォルダでも軽快です。

macOS 版をダウンロードv1.4 · DMG · 3.9 MB GitHub で見る

GPL-3.0 · アドホック署名。初回起動を参照 · アプリの表示は英語です

左はリスト、右はアイコン。サイドバーにはよく使う項目、ドライブ、ワークスペース。

ネイティブAppKit のテーブルとグリッド。Electron でも Web ページでもありません。
3.9 MBダウンロードはこれだけ。ランタイムは不要です。
50 ステップコピー、移動、名前変更、ゴミ箱への移動を取り消し・やり直しできます。
無料GPL-3.0。アカウント不要、テレメトリなし、試用期間なし。

実際の動き

5枚の写真を、キー1つで

左でファイルを選び F5 を押せば、もうバックアップディスクの中。Tab と ⌘2 で反対側のペインに移り、サムネイルで確認できます。

試してみる

2つのペイン、1操作に1キー

      機能

      ファイルマネージャーに必要なことを、キーボードから手を離さずに

      2ペイン、タブ、3つの表示

      Tab · ⌘1 ⌘2 ⌘3

      リスト、アイコン、プレビュー列付きの Finder 風カラム。ペインごとに履歴を持ち、フォルダごとに並び順を記憶し、ウインドウのタブを名前付きのセットとして保存できます。

      Total Commander の操作感

      F5 · F6

      反対側のペインへのコピーと移動、タイプして選択、*.jpg のようなパターンで選択、選択の反転。⇧⌘C で複数のフォルダからファイルを集め、まとめてペーストできます。

      バックグラウンドのファイル操作

      ⌘Z · ⇧⌘Z

      コピー、移動、複製、ゴミ箱、名前変更はバックグラウンドで実行され、一時停止やキャンセルもできます。取り消しは 50 段階まで戻れ、再起動後も使えます。

      アーカイブ

      zip · tar.gz/bz2/xz

      システムのツールでアーカイブの作成・展開・閲覧ができ、パスワード付き ZIP にも対応。展開時は zip-slip パスを防ぎます。

      ワークスペース

      symlinks

      ディスクのあちこちにあるファイルを、リンクの入った1つのフォルダに集めます。コピーも移動もせず、項目を削除してもリンクが消えるだけです。

      検索、フィルタ、プレビュー

      ⌘F · ⌥⌘F · Space

      部分一致や正規表現での再帰検索、即時フィルタバー、スペースキーでクイックルック。情報パネルではテキスト、コード、PDF、画像、動画などファイルそのものをプレビューできます。

      macOS になじむ

      Finder · AirDrop · SMB

      Finder とのドラッグ＆ドロップ、カラータグ、AirDrop、ターミナルで開く、SMB 共有への接続、ドライブの取り出し、.dmg からのアプリインストール。情報ウインドウでアクセス権を変更できます。USB メモリにコピーしても ._ ファイルは残りません。

      自分好みのショートカット

      ⌘, · ⌘?

      すべてのキー割り当ては設定で変更できます。よく使う項目 1〜9 は ⌥⌘1〜⌥⌘9、一覧はヘルプにあります。

      コマンドパレット

      ⇧⌘P · ⇧⌘G

      メニューのすべてのコマンドを、あいまい検索ですぐに呼び出せます。「フォルダへ移動」はパスを入力して Tab で補完でき、パスバーの / をクリックすると隣のフォルダが一覧できます。

      フォルダの比較

      ⇧F2 · ⌘← ⌘→

      ワンキーで、片側にしかない項目や新しい方の項目を両側で選択します。⌘←・⌘→ でフォルダを反対側のペインに開きます。

      ユーザーコマンド

      Commands · zsh

      Commands メニュー、コマンドパレット、ショートカットから、選択したファイルに自分のシェルスクリプトを実行できます。一時停止とキャンセルにも対応し、Total Commander のユーザーコマンドと同じ感覚で使えます。

      メタデータで名前変更

      [Date] · [Track]

      新しい名前をすべてプレビューしながら一括変更。日付と時刻は EXIF や動画から、トラック番号・アーティスト・タイトルはオーディオタグから取得し、大文字・小文字の変換もできます。

      フォルダの同期

      ⌥⇧F2

      2 つのフォルダツリーを比較し、実行前にすべての差分とその操作を確認できます。双方向または一方向。置き換えたファイルや削除したファイルはゴミ箱に移動します。

      容量の行方

      ⌥⌘S · ⌥⌘L

      各項目の割合を示すバー付きのフォルダサイズと、「最大のファイル」：フォルダ以下のどこにあっても最も大きいファイルを一覧し、ワンキーでペインに表示します。

      インストール

      1分で使い始められます

      1. ディスクイメージをダウンロード。
        Marlia-1.4.dmg、または Releases から任意のバージョン。
      2. Marlia を「アプリケーション」にドラッグ。
        イメージにはアプリと「アプリケーション」へのショートカットが並んでいます。
      3. 最初の1回は手動で開きます。
        Marlia.app を右クリックして「開く」を選びます。macOS 15 以降では「システム設定」→「プライバシーとセキュリティ」で「このまま開く」をクリックします。
      4. 任意：フルディスクアクセスを許可。
        デスクトップ、書類、ダウンロードを開くたびに確認が出なくなります。

      macOS が最初に確認する理由

      Marlia は Apple Developer ID なしのアドホック署名なので、初回起動時に Gatekeeper に止められます。「壊れているため開けません」と表示された場合（ブラウザでのダウンロードや AirDrop の後によくあります）は、隔離フラグを外してください：

      xattr -cr /Applications/Marlia.app

      自分でビルドしたい場合も簡単です。Xcode プロジェクトはなく、スクリプト1つだけ：./build.sh --run
