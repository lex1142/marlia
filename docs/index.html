A free, native two-pane file manager for the Mac

In the spirit of Total Commander, for people who live on the keyboard: F5 copies to the other pane, F6 moves, Tab switches, and every shortcut can be changed. Built on native AppKit, it stays fast in folders with thousands of files.

      Five photos, one key

      Select files on the left, press F5, and they are on the backup drive. Tab and ⌘2 switch to the other pane and show them as thumbnails.

      Everything a file manager should do, without leaving the keyboard

      Two panes, tabs, three views

      Tab⌘1⌘2⌘3

      List, Icons and Finder-style Columns with a preview column. Each pane keeps its own history, every folder remembers how you sorted it, and a window's tabs can be saved as a named set.

      The Total Commander workflow

      F5F6

      Copy and move to the other pane, type to select, select by pattern such as *.jpg, invert the selection. Gather files from several folders with ⇧⌘C and paste them all at once.

      Background file operations

      ⌘Z⇧⌘Z

      Copy, move, duplicate, trash and rename run in the background with pause and cancel. Undo goes back 50 steps and survives a restart.

      Archives

      Create, extract and browse archives with the system tools, including password-protected ZIP. Extraction is guarded against zip-slip paths.

      Workspaces

      Gather files from all over the disk into one folder of links. Nothing is copied or moved, and removing an item only removes the link.

      Search, filter, preview

      ⌘F⌥⌘FSpace

      Recursive search by substring or regex, an instant filter bar, Quick Look on Space, and an info panel that previews the file itself: text, code, PDF, images, video.

      At home on macOS

      Drag and drop with Finder, color tags, AirDrop, Open in Terminal, SMB shares, ejecting drives and installing apps straight from a .dmg. Get Info edits permissions. Copies to USB sticks leave no ._ files behind.

      Favorites from the keyboard

      ⌥⌘1…9⌘,

      Favorites 1 to 9 open with ⌥⌘1 to ⌥⌘9, in the order of the sidebar. Settings lists every shortcut, and that's where you change them.

      Command palette

      ⇧⌘P⇧⌘G

      Every menu command is a few keystrokes away, found by fuzzy search. Go to Folder takes a typed path with Tab completion, and each / in the path bar opens the folders next to it.

      Compare folders

      ⇧F2⌘←⌘→

      One keystroke selects what is missing or newer on each side. Open a folder in the other pane with ⌘← and ⌘→.

      Your own commands

      Run your shell scripts on the selected files from the Commands menu, the palette or a shortcut, with pause and cancel, like user commands in Total Commander.

      Rename by metadata

      Batch rename with a live preview of every new name: date and time from EXIF or video, track, artist and title from audio tags, and case conversion.

      Synchronize folders

      ⌥⇧F2

      Compare two folder trees and review every difference with its action before anything happens. Both ways or one way; replaced and deleted files go to the Trash.

      Where the space went

      ⌥⌘S⌥⌘L

      Folder sizes with a bar for each item's share, and Largest Files: the biggest files anywhere under a folder, one keystroke from the pane.

      Seven looks, checked for contrast

      Every palette keeps file names readable at 4.5:1 or better, on the pane and on the selection.

      Get it running in a minute

      1. Download the image.
        Marlia-1.4.dmg, or any version from Releases.
      2. Drag Marlia onto Applications.
        The image has the app and an Applications shortcut side by side.
      3. Open it once by hand.
        Right-click Marlia.app and choose Open. On macOS 15 and later, go to System Settings → Privacy & Security and click Open Anyway.
      4. Optional: grant Full Disk Access.
        Then Desktop, Documents and Downloads open without repeated prompts.

      Why macOS asks first

      Marlia is signed ad hoc, without an Apple Developer ID, so Gatekeeper stops it on first launch. If macOS says the app “is damaged and can’t be opened”, which often happens after a browser download or AirDrop, clear the quarantine flag:

      xattr -cr /Applications/Marlia.app

      Prefer to build it yourself? There is no Xcode project, just one script: ./build.sh --run.

      Privacy

      • The Marlia app sends nothing anywhere: no analytics, no crash reports, no update checks. It only goes to the network when you ask it to, for example to connect to an SMB server.
      • This site uses no cookies, analytics or tracking. Fonts and images are served from the site itself.
      • The language you pick is remembered in your browser (local storage) and is never sent anywhere.
      • To show the latest version, the page asks the GitHub API about Marlia's releases once per visit. GitHub receives your IP address with that request.
      • The site is hosted on GitHub Pages. Like any web host, GitHub logs requests, including IP addresses. See the GitHub Privacy Statement.
